|---|---|---|
| 乙方宝 | 公开列表分页、公告详情、公开附件链接 | 会员隐藏正文保留限制提示，不承诺获取隐藏内容 |

## 页面依据

- 乙方宝：`/search/invitedBidSearch` 的 `pageNo` 分页和 `/inviteBid/detail/YYYYMMDD_ID.html`；只解析详情正文容器，避免侧栏广告命中。
- 国家能源：入口改为 `https://www.chnenergybidding.com.cn/bidweb/`。列表 `/bidweb/001/001002/moreinfo.html` 覆盖货物、工程、服务，跟随页面“下页”链接；详情仅接受 `001002` 招标公告路径。正文取 `.con`，发布时间取 `.info-sources`，公开附件从 `.article` 内提取。旧 e购询价适配仅保留兼容代码，不再作为新增平台注册，不迁移或冒充其历史来源。
- 中广核：`zbgg.html` 中 `window.pageId` 和 `window.struct` 提供组件、数据集；前十页读取 `content/.../N.json`，后续使用页面脚本调用的 `/portalApi/content/queryPage`。详情 `detail/{dataId}/{detailId}.json` 的 `Body`、`Attachment`、`BodyAttachment` 提供正文与文件，附件去重。
- 公共服务平台：首页链接的 bulletin 列表把详情跳转到 ctbpsp.com，并出现交互验证码。不绕过验证，不把验证页入库。
- 电力设备信息网：返回 HTTP 405 和“您已被纳入黑名单”提示。不尝试更换网络规避限制。
- 中国华电：官网明确区分招标公告与谈判、竞价、询比采购公告。适配器只读取 `staticPage/zxzbggJT.html` 招标入口；412 或挑战脚本会明确要求人工验证，验证页不会入库。

## 采集语义

- 复用现有回溯日期、类型和关键词规则，以及回收站阻止重新入库的规则。
- 每个可采集适配器受最大页数和候选条数限制；页面无新 ID 即停止；已入库或回收站 ID 不重复返回。
- 公开内容不完整时，持久保存 `collection_warning` 抽取字段并写入摘要、日志，状态为部分解析。未命中的只进入“可能漏匹配”；完整解析且未命中仍按原规则丢弃。
- 本地重解析不会消除网站内容权限限制；获取完整内容后重新导入可清除旧限制。健康检查正常只代表当前公开范围可访问，不代表会员内容可获取。
- 批次日志把“可能漏匹配保留”与真正关键词命中分开。新增入库数量包括新保留的待核查记录。
- 新平台通过幂等初始化注册，不修改既有任务、关键词或自动新增采集计划。运行中的旧服务需重启后加载后端及平台种子。
