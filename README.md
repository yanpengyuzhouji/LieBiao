## 项目简介

猎标面向招标信息的日常跟踪场景：从公开平台按关键词采集招标公告，抓取正文与公开附件，抽取结构化字段，输出关键词命中证据，并允许人工标记、修订、复用与永久清理。

系统为**单机部署**，不依赖外部数据库或中间件：

- **业务数据**：SQLite（`scout.db`）
- **文件数据**：公告原始页面、附件、解压文件、解析文本、预览文件
- **交互方式**：本机 `127.0.0.1` 上的 Web 管理端，Windows 打包版附带托盘与启动窗口

设计依据为《招标信息采集管理系统——分步设计文档》，V2 可行性结论见 [`docs/V2可行性与V1验收说明.md`](docs/V2可行性与V1验收说明.md)。

## 核心能力

| 模块 | 说明 |
|---|---|
| 平台适配 | 统一适配器接口，覆盖公开列表、详情、公开附件与健康检查；平台差异收敛在 `backend/adapters.py` 与 `backend/public_platforms.py` |
| 采集任务 | 任务绑定关键词组，配置回溯天数、最大页数、候选上限、请求间隔与重试策略；支持单任务运行与一键运行全部 |
| 关键词命中 | 支持包含/全部/短语/排除/同义词规则，证据按规范化字符映射回原文，可定位到高亮片段 |
| 结构化抽取 | 从正文抽取项目编号、采购人、代理机构、预算、开标时间等字段；人工修订优先，自动解析不覆盖人工值 |
| 附件与解析 | PDF / DOCX / XLSX / 文本 / HTML 解析，ZIP 安全解压（Zip Slip、深度、文件数与体积上限），扫描件可选 OCR |
| 公告版本 | 原始页面按版本保存，内容指纹去重，保留历史版本与证据链 |
| 人工验证会话 | 平台安全验证时打开独立 Edge 窗口，验证后本机会话回绑采集任务，Cookie 仅存本机数据库 |
| 公告库 | 服务端分页与筛选（今日新增 / 待确认 / 重点关注 / 解析异常 / 可能漏匹配 / 回收站），业务标记、批量操作、CSV 导出 |
| 导入中心 | URL 导入、Excel 导入、文件导入，均复用平台识别与关键词规则 |
| 回收站 | 软删除、恢复、永久删除与清空；永久删除写入最小排除标记，阻止同一条公告被再次采集 |
| 更新检查 | 启动时检查一次，运行期每小时静默轮询 GitHub Releases 公开接口；失败不提示、不阻塞采集 |
| 系统日志 | 采集批次、策略过滤、关键词变更、任务启停、导入与删除等操作留痕 |

接口层提供 50 余个 REST 接口，交互式文档位于 `http://127.0.0.1:<port>/api/docs`。

## 快速开始

### 方式一：仅查看界面（零依赖）

直接双击 `index.html`。此方式使用页面内置演示数据，不连接后端。

### 方式二：开发模式运行（真实数据库）

```bash
python3 -m pip install -r requirements.txt
python3 run_app.py
```

程序会自动打开 `http://127.0.0.1:8091`，API 文档位于 `http://127.0.0.1:8091/api/docs`。

Windows 上建议使用 `py run_app.py`。

### 方式三：Windows 安装包（面向最终用户）

1. 将 `release/LieBiao-Setup-1.2.5-win-x64.exe` 复制到目标 Windows 10/11 64 位电脑并运行，**无需另装 Python**。
2. 选择程序安装位置，再选择**独立的数据存放位置**（不要放在程序安装目录内部或磁盘根目录）。
3. 安装后从桌面或开始菜单启动；系统打开本地浏览器界面与启动窗口。

配置保存在 `%LOCALAPPDATA%\LieBiaoDesktop\storage.json`，数据库与附件保存在安装时选定的数据目录。完整说明见 [`release/安装使用说明.md`](release/安装使用说明.md)。

### 自行打包

在 Windows 开发机执行：

```powershell
packaging\build_windows.ps1
```

产物位于 `dist\LieBiao\LieBiao.exe`，安装包位于 `release\LieBiao-Setup-<版本>-win-x64.exe`。

> **OCR 打包注意**：PaddlePaddle 没有 Python 3.14 的 wheel，含 OCR 的构建须使用 Python 3.9–3.13，并先安装 `requirements-ocr.txt`。

### 托盘行为（打包版）

启动后在右下角创建托盘图标。关闭主窗口只隐藏到托盘；托盘菜单可打开系统、打开数据目录、检查版本更新或退出系统。**只有选择"退出系统"才会停止定时采集**；关机、休眠或应用未运行时，不执行定时采集。

## 采集平台支持矩阵

系统注册 12 个平台，其中 **10 个处于启用状态**。下表为当前实现范围与实测边界，实测结论来自 [`docs/crawl-platform-test-report.md`](docs/crawl-platform-test-report.md)。

| 平台 | 采集模式 | 已实现范围 | 限制 |
|---|---|---|---|
| 南方电网 | 公开 | 列表分页、详情、公开附件 | 部分公告无公开附件，属正常情况 |
| ECP2.0 | 公开 / 会话 | 列表、详情、公告 ZIP 及嵌套附件 | 招标文件购买仍需登录，不在采集范围 |
| 国网交易专区 | 公开 / 会话 | 列表、详情、公告 ZIP | 同上 |
| 中国石化物资 | 公开 | 列表、正文 | 附件下载场景覆盖有限 |
| 中国华能 | 公开 / 会话 | 列表分页、详情正文 | 触发平台安全验证时明确失败，不入库验证页 |
| 大唐集团 | 公开 / 会话 | 列表分页、详情正文 | 同上 |
| 乙方宝 | 公开 / 会员 | 公开列表分页、详情、公开附件；有效会员可走企业接口取完整正文 | 无会员权限时降级为公开采集，会员隐藏正文不承诺获取 |
| 国家能源（国能e招） | 公开 | 招标公告栏目下的货物/工程/服务分页、正文、公开附件 | 只读招标公告，不采询价、资格预审、中标与终止公告 |
| 中广核 | 公开 | 招标公告分页、完整正文、公告 PDF | 仅当前招标公告栏目 |
| 中国华电集团电子商务平台 | 公开 / 会话 | 招标公告入口、分页、详情、公开附件、人工验证会话 | 当前环境列表返回 412 安全验证，须人工验证后复测 |

**已下架平台（V1.2.4 起）**：中国招标投标公共服务平台（`ceb`）、中国电力设备信息网（`espic`）。二者无法稳定完成无人值守的列表+详情采集（前者详情跨域且含交互验证码，后者返回黑名单拦截页），站点行保留仅用于历史公告外键追溯，页面不再展示、任务自动停用。

### 人工验证会话

"平台与账号"页面可为需要验证的平台打开独立 Edge 人工验证窗口。验证完成后系统在本机读取该平台会话、执行真实列表检查，并把有效会话绑定到采集任务：

- 未显式绑定账号的任务、URL 导入与健康检查共用最近的有效验证会话
- 显式绑定失效时**停止**，不擅自切换到其他账号；跨平台绑定不可用
- 已停用、已过期、到期时间格式错误或缺少凭据的账号不会被复用
- 调试端口写入账号记录，应用重启后仍可接管已打开的验证窗口
- Cookie 仅保存在本机数据库，不写入日志

## 采集策略与范围约束

- **回溯天数**按北京时间自然日计算：`0` 表示仅当天，`1` 表示从昨天 00:00 起。
- 列表元数据与详情数据两个阶段都会校验发布时间与公告类型；**缺少可解析发布时间的记录不会自动入库**，并写入"策略过滤"日志。
- 任务配置的请求间隔覆盖列表、详情与附件请求；最多尝试次数在运行时强制执行。
- 每个适配器受最大页数与候选条数限制；页面无新 ID 即停止；已入库或回收站中的 ID 不重复返回。
- 已下架平台的采集任务自动停用，启用时返回明确错误。
- 关键词证据按任务自身的关键词组清理与写入，避免覆盖其他规则组结果；AND 条件的同义词按替代项计算，无正向条件的规则不会只凭排除词产生匹配。
- 公开内容不完整时持久保存 `collection_warning` 抽取字段并写入摘要与日志，状态为**部分解析**；未命中的只进入"可能漏匹配"，完整解析且未命中仍按原规则丢弃。
- 批次日志区分关键词命中、首次新增、重复更新、策略过滤与失败数量。

**关于"漏匹配"的语义**：完整解析成功但未命中关键词的公告会被丢弃，仅保留用于去重与审计，不会出现在列表中。"可能漏匹配"只展示未命中**且**存在解析异常或待处理附件的公告。

## 文档解析能力

| 格式 | 组件 | 状态 |
|---|---|---|
| PDF（文本型） | PyMuPDF | 随程序打包 |
| DOCX | python-docx | 随程序打包 |
| XLSX | openpyxl | 随程序打包 |
| 文本 / HTML | 内置解析器 | 随程序打包 |
| ZIP | 内置安全解压 | 随程序打包，含 Zip Slip、深度、文件数与体积上限 |
| DOC（旧版） | Microsoft Word | **依赖目标电脑安装可用的 Word** |
| 扫描件 PDF / 图片 | PaddleOCR PP-OCRv6-small（CPU） | V1.2.3 起随包内置模型，需显式启用 |

同一附件已有有效本地文件且哈希一致时不重复下载；压缩包子文件身份包含父附件与相对路径。解析失败或待处理的附件在重新解析时会自动使用当前解析器重试，并据此决定 `parsed` / `partial` 状态。

## 版本更新检查

后端启动后通过 GitHub Releases 公开接口检查一次新版本，运行期间每小时由**独立线程静默检查**；检查失败不提示、不占用采集线程。同一新版本只提示一次，点击右上角通知按钮可打开下载页。

- 通过 `LIEBIAO_UPDATE_ENABLED=false` 关闭
- 通过 `LIEBIAO_UPDATE_URL` 指向其他 HTTPS JSON 更新清单
- 发布新版本时需在 GitHub 创建对应 Release（例如 `v1.3.0`）并上传安装包

## 测试与验收

实网验收脚本：

| 脚本 | 用途 |

| `scripts/live_acceptance.py` | 三平台列表、详情、公开附件实时验收 |

#### V1.2.5 — 专用浏览器持久化与定时采集恢复

- 验证完成后复用原有 Edge Profile，转入最小化后台运行，不再创建带时间戳的临时 Profile。
- 健康检查与定时采集前自动接管已验证的调试端口；端口变化时同步更新本地会话凭据。
- 浏览器请求增加超时、中断和断线处理，避免专用浏览器无响应直接造成接口 500。
- 验证窗口句柄失效时改以调试端口判断浏览器是否仍可用。
- 新增会话恢复与浏览器超时回归测试，完整测试套件通过。

#### V1.2.3 — 乙方宝会员采集重做与扫描件 OCR

**乙方宝（`yfb`）**
- 采集前用会员接口判定账号状态，仅有效会员走企业接口与企业详情页取完整正文。
- 详情页改为在验证窗口内导航并捕获站点自身的详情响应，避免哈希路由复用导致的重复内容。
- 无会员权限时明确降级为公开采集，并写回平台状态与提示，不再误报成功。

### 迭代过程中解决的关键问题

| 问题 | 处理 |
|---|---|
| 全角字符、连续空白、大小写折叠导致关键词证据定位偏移 | 按规范化字符映射回原文定位 |
| 采集任务互相覆盖其他规则组的关键词证据 | 按任务绑定的关键词组清理与写入，并补录绑定关系 |
| 去重按全局判断导致跨任务误判 | 去重按当前任务绑定的关键词组判断，候选扫描不再固定限制为目标数量五倍 |
| 慢网络下载附件期间长时间占用 SQLite 写锁 | 附件下载前先提交元数据事务 |
| 公告原始页面被固定文件名覆盖，丢失历史版本 | 原始页面按版本保存 |
| 自动解析覆盖人工修订的字段 | 自动字段更新不覆盖已存在的人工修订值 |
| 界面在后端不可用时显示演示公告与假管理数据 | 后端断开时不再回退演示数据 |
| 解析过程中附件被删除，写入失效外键 | 解析前后校验附件身份，跳过失效外键 |
| Windows 上 `msedge.exe` 常为启动器进程，句柄死亡导致验证窗口被误判关闭 | 改以调试端口而非 `Popen` 句柄判断存活 |
| 已下架平台仍在总览与任务列表中可选 | V1.2.4 起站点、任务与账号统一停用并隐藏 |

## 已知限制与后续计划

**当前限制**

- 旧版 `.doc` 解析依赖目标电脑安装可用的 Microsoft Word。
- 扫描图片类 PDF 需显式启用 OCR；未启用时不能保证关键词识别。
- 乙方宝会员隐藏正文不承诺获取；国家能源只采招标公告栏目。
- 华能、大唐、华电首次触发安全验证时仍需人工验证；验证成功后由专用浏览器后台持久运行，平台会话过期时仍需重新验证。
- 网站访问、网络出口限制及平台改版仍可能影响采集；健康检查正常仅代表当前公开范围可访问。
- 安装包未进行代码签名，Windows 可能提示来源未知。

**待完成验收**

- 目标 Windows 电脑上的 `.exe` 构建与升级恢复测试（尚未在另一台全新电脑完成端到端验收）。
- 华能、大唐、华电在有效人工验证后的真实采重复测。
- 连续 72 小时运行稳定性验收。
- 三平台目标网络出口的复验（此前实测出现连接重置与 SSL 握手超时）。

后续规划见 [`docs/V2可行性与V1验收说明.md`](docs/V2可行性与V1验收说明.md)：V2 可在 V1 保存的原始页面、附件与解析文本之上实施语义匹配、相关性评分、摘要与公告关联。

## 合规边界

- 平台采集严格使用**公开页面**或**已授权会话**。
- **验证码、短信与 CA 认证不做绕过**；验证页与限制页明确失败，不写入公告库。
- 遇到访问限制（黑名单、412、挑战脚本）时如实报告，不更换网络规避限制。
- 会话 Cookie 仅保存在本机数据库，不写入日志，不进入测试报告。
- 不采集会员隐藏内容、需登录购买的招标文件正文。
- 系统仅在本机回环地址提供服务，不对外暴露。
