# V2 可行性与 V1 验收说明

## 结论

V2 可行。三个目标平台的公告数据都可以在不登录的情况下采集：ECP2.0 和国网交易专区有门户自身使用的公开 JSON 接口，南方电网公告页为服务端输出的完整 HTML。V2 的 OCR、语义匹配、相关性评分、摘要和公告关联都可在 V1 保存的原始页面、附件和解析文本上实施。

## 2026-09-04 实际勘探结果

| 平台 | 列表 | 详情 | 公开附件 | 登录结论 |
|---|---|---|---|---|
| ECP2.0 | `ecpwcmcore/index/noteList` | `ecpwcmcore/index/getNoticeBid` | `ecpwcmcore/index/downLoadBid` 返回 ZIP | 样例公告及公告 ZIP 无需账号 |
| 国网交易专区 | `ecpwcmcore/index/noteList` | `ecpwcmcore/index/getNoticeBid` | `ecpwcmcore/index/downLoadBid` 返回 ZIP | 样例公告及公告 ZIP 无需账号 |
| 南方电网 | `/zbgg/index[_N].jhtml` | `/zbgg/{id}.jhtml` | 按详情页公开链接下载 | 样例公告无需账号 |

样例验证包括：列表发现、公告 ID、标题、项目编号、采购/招标人、代理机构、发布时间、开标时间、正文和公告 ZIP。两个国网样例 ZIP 实际响应均为 HTTP 200 且文件头为 ZIP。

## 边界和风险

- “公告可采集”不等于“招标文件购买/获取无需登录”。系统只使用公开公告与公开公告附件，不绕过验证码、短信或 CA。
- 平台前端路由和接口可能调整，需要保留健康检查、限速、失败日志和适配器回归。
- 南网不是每条公告都有附件；没有附件的样例应以“正常无附件”验收，不能当作采集失败。
- 30 条/平台的长期稳定性样本库属于运行基线，需在商务部电脑的真实网络出口上持续积累；本次以指定三条样例和实时列表完成功能验收。
